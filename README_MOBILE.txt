KHL MANAGER — MOBILE EDITION 6.2
================================

Что внутри
- index.html — игра с мобильной адаптацией.
- db.js — база игроков (608 игроков / 22 клуба).
- manifest.webmanifest — параметры установки на экран Android.
- sw.js и pwa.js — регистрация PWA и кэширование оболочки для повторного/офлайн-запуска.
- icons/ — иконки приложения.

Важно об установке
PWA устанавливается только при открытии сайта через HTTPS (либо localhost для разработки). Простое открытие index.html как локального файла на Android не активирует установку и Service Worker.

Как опубликовать
1. Распакуй архив.
2. Загрузи ВСЕ файлы и папку icons на HTTPS-хостинг со статическими файлами (например, GitHub Pages, Netlify или Cloudflare Pages). Сохрани структуру каталогов.
3. Открой URL index.html в Chrome на Android.
4. Нажми «Установить KHL Manager» (если браузер предложил кнопку) или меню Chrome ⋮ → «Установить приложение» / «Добавить на главный экран».
5. Запусти игру с новой иконки. После первого успешного загрузочного сеанса основные файлы будут кэшироваться для офлайн-старта.

Если меняешь файлы вручную, убедись, что db.js лежит рядом с index.html. Не удаляй manifest.webmanifest, pwa.js, sw.js или папку icons — без них приложение не будет устанавливаться как PWA.

Формулировка плей-офф обновлена: «Плей-офф начнётся автоматически после того, как будут сыграны все матчи регулярного чемпионата.» Число 748 не привязано к тексту статуса — проверка завершения опирается на факт, что все матчи регулярки сыграны.

Совместимость
- Android: Chrome и другие браузеры на базе Chromium с поддержкой PWA.
- На компьютере игра также открывается в обычном браузере.
- Сохранения продолжают использовать localStorage браузера. Для переноса на другое устройство используйте экспорт/импорт файла сохранения; синхронизация между устройствами в этой версии не включена.

Версия: Mobile Edition 6.4 (на основе Development Edition 6.0).


Исправления 6.2 — прокрутка и Telegram
- Отключена глобальная плавная прокрутка, которая могла создавать ощущение задержки при взаимодействии с WebView.
- Вертикальные жесты страницы снова используют нативную прокрутку; у журнала матча убрана вложенная ограниченная прокрутка на телефоне.
- Интерактивный матч продолжает симулироваться, но перерисовка площадки и журнала выполняется только при открытой вкладке «Матч-центр» и не чаще одного раза примерно за 0,9 секунды.
- Журнал больше не прыгает вниз, если пользователь прокручивает историю событий вверх.
- При запуске внутри Telegram Mini App игра запрашивает раскрытие окна и синхронизирует высоту с viewport Telegram.
- Service Worker использует новый cache key khl-manager-mobile-6-2: после публикации замени все файлы из архива и перезапусти Mini App, чтобы старая оболочка была удалена.


Визуальная редакция 6.4
- Во вкладке «Обзор» убран блок с турнирной таблицей.
- Турнирная таблица упрощена: сохранены победы в основное время, овертайме и по буллитам, поражения и очки; убраны шайбы, разница и отдельный столбец поражений в пустые ворота.
- В календаре отображается весь список матчей команды в прокручиваемой области. Ближайший несыгранный матч выделен.
- Во вкладке «Состав» редактор звеньев расположен выше списка игроков; добавлено отдельное сохранение состава без запуска матча.
- Убраны кнопки обновления в разделах «Развитие» и «Ход матча», а также блок архива сезонов в статистике.
- В финансах убраны столбец позиции и поясняющая сноска; список игроков отображается целиком.
- В Матч-центре арена и посещаемость показаны над счётом; завершённые матчи подписываются «Матч завершён», а рядом с автором гола показывается счёт после шайбы.
- Вкладка «Матч-центр» перенесена между «Кубок Гагарина» и «Календарь»; кнопка экспорта убрана из верхней панели.

После публикации замени файлы из архива на GitHub Pages. Service Worker использует новый ключ кэша khl-manager-mobile-6-4, чтобы браузер загрузил обновлённую оболочку.


Обновление 6.4
- В полной турнирной таблице на мобильных экранах включена горизонтальная прокрутка всей таблицы: названия клубов перемещаются вместе со статистикой.
- В главное меню добавлена кнопка «Экспортировать сохранение в файл» перед кнопкой загрузки. Сохранение выгружается в JSON-файл; на телефоне браузер может предложить выбрать папку или сохранить в «Загрузки».
- Перед импортом нового сохранения выводится подтверждение, если уже существует текущая карьера.
- Service Worker использует кэш khl-manager-mobile-6-4.
